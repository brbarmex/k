Início / Fail path / C10

C10 — Apps da AWS fora, replicação viva: tráfego vai para a Azure

Fail path
Status na fonte: ✅ Atualizado (modelo v1)

1. Visão geral do cenário

As células de aplicação da AWS falham, mas a camada de replicação e a líder continuam vivas. O Agent pede ao Compass-Router para mandar o tráfego à Azure. O DataReplication da Azure encaminha as escritas à líder na AWS pelo link dedicado. Se não alcança a líder, devolve erro recuperável e nunca escreve localmente. RPO = 0, sem promoção e sem risco de split-brain.

3. Legenda e etapas

  1. O Agent manda rotear o shard para a Azure.
  2. A app em Z1 chama o DataReplication local.
  3. Ele encaminha à líder AWS (1 salto) pelo link dedicado.
  4. A líder executa a escrita completa (C03) e responde.
  5. Se a líder não for alcançável, o erro é recuperável; nenhuma escrita local.

1O link vira caminho quente Falhas e tratativas

Contexto
Com as apps da AWS fora, cada escrita vinda da Azure cruza o link duas vezes: o encaminhamento para a líder e a replicação de volta. O link passa a carregar tráfego de cliente além da replicação, o que pode levar à faixa cinzenta e, por ela, a latência alta ou degradação.
O que a fonte define
Dimensionar o link e considerar QoS (C25).
Sugestão de encaminhamento (inferência, não decidida)
Medir no spike S1 a banda necessária nesse cenário (forward mais replicação para 3 learners) e definir QoS que priorize a replicação. Ponto não coberto: se o link satura, a replicação atrasa e o shard pode degradar, abrindo RPO > 0 por causa de tráfego de cliente.

2Router manda tráfego à Azure com o link fora Falhas e tratativas

Contexto
Se o Agent direciona o tráfego à Azure enquanto o link está fora, a Azure não alcança a líder e todas as escritas falham. O cliente fica sem escrita embora a AWS esteja viva.
O que a fonte define
O DataReplication responde erro recuperável e nunca escreve localmente; dependência externa registrada.
Sugestão de encaminhamento (inferência, não decidida)
Pedir ao dono do Agent que a decisão de roteamento consulte o estado do link, e incluir no exercício de falha a combinação apps AWS fora e link fora, medindo o tempo até alguém perceber.
